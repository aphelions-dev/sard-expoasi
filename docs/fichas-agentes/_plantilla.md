# Ficha: agente de <nombre>

| Campo | Contenido |
|-------|-----------|
| Objetivo | Qué decide o produce, en una frase. |
| Entradas | Qué eventos o datos lee. |
| Salidas | Qué eventos escribe. |
| Herramientas | APIs, modelos (Jev) o funciones que usa. |
| Memoria | Qué recuerda y dónde. |
| Límites de autonomía | Qué nunca hace sin humano. |
| Manejo de errores | Qué pasa si falla una entrada o una herramienta. |
| Criterio de terminación | Cuándo da por terminado su trabajo sobre un reporte o incidente. |
