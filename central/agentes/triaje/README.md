## Alcance

Asignar tipo y prioridad final. Primero reglas; luego Jev puede subir la prioridad, nunca bajarla. Si Jev falla o tarda, queda la de reglas.

## No le toca

Bajar una prioridad, agrupar reportes, proponer acciones.
